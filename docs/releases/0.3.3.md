# MonoTerm 0.3.3

## 新增

- 增加独立的“关于 MonoTerm”窗口，可从应用菜单打开，展示应用图标、简介、版本号、运行平台和构建技术，并提供 GitHub 项目与版本下载入口。
- 关于窗口支持中英文及深浅主题；版本号自动读取构建元数据。重复打开会聚焦已有窗口，无主窗口时也可以查看。

## 修复

- 关闭按钮和 `⌘W` 统一为关闭当前窗口，关闭最后一个窗口后应用仍继续运行。
- `⌘Q` 用于退出整个应用，在没有窗口时同样有效。
- 所有窗口关闭后，点击 Dock 图标或按 `⌘T` 可以重新打开主窗口。
- 主窗口、Herdr 和设置窗口保持独立关闭；标签页及窗格编辑弹窗不再拦截 `⌘W`。关闭 Herdr 窗口只解除界面连接，不会关闭守护进程中的终端。

## 下载与更新

- 适用于 Apple Silicon Mac，要求 macOS 14 或更高版本。
- 下载 `MonoTerm-0.3.3-arm64.zip`，或在正常启动的应用中通过“设置 → 版本”检查更新。
- `SHA256SUMS` 提供安装包校验值，`appcast.xml` 提供带 Ed25519 签名的 Sparkle 更新信息。
- 安装更新会重启 MonoTerm 并关闭本地终端会话，请先完成正在运行的任务；Herdr 守护进程中的会话继续运行。
- 安装包使用 ad hoc 代码签名，未进行 Apple 公证。
