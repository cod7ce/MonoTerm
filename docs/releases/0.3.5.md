# MonoTerm · ONES 0.3.5

## 更新内容

- 应用名称统一为 **MonoTerm · ONES**，应用包、包内可执行文件及 macOS 显示名称均包含 `ONES`。
- 同步更新主窗口、Herdr 窗口、应用菜单、关于页和设置中的中英文名称。
- 更新构建、启动和发布脚本，安装包名称为 `MonoTerm-ONES-0.3.5-arm64.zip`。
- 保留原有应用标识、配置目录、更新源及签名密钥，已有偏好设置无需迁移。

## 安装

下载 `MonoTerm-ONES-0.3.5-arm64.zip`，解压后将 `MonoTerm · ONES.app` 放入“应用程序”目录。支持 Apple Silicon Mac，要求 macOS 14 或更高版本。已有版本可通过“设置 → 版本”检查更新。

安装更新会重启应用并关闭本地终端会话，请先完成正在运行的任务；Herdr 守护进程中的会话继续运行。

安装包附带 SHA256 校验和及 Sparkle Ed25519 更新签名。应用采用 ad-hoc 签名，未进行 Apple 公证。
